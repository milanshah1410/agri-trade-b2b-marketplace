# AGRI TRADE – All India B2B Agriculture Marketplace

B2B agriculture commodities e-commerce and logistics platform.

Planned stack: Laravel, Vue 3, Inertia.js, Tailwind CSS, Filament, Spatie Permission, MySQL 8, Razorpay, Google Maps.

Status: Phase 1 (architecture and planning). See `docs/PHASE1_ARCHITECTURE.md`.
